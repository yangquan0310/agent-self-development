# ADR-012：工具返回值统一适配

> **状态**：建议中  
> **日期**：2026-05-19  
> **决策优先级**：🟡 P1  
> **可逆性**：可逆

---

## 背景

OpenClaw 新插件规范要求工具返回特定格式：

```json
{
  "content": [{ "type": "text", "text": "JSON字符串" }]
}
```

但 Tool Handler 编写者更关注业务逻辑，不应在每个 handler 中重复 `JSON.stringify` 和包装逻辑。

---

## 决策

**所有 Tool Handler 返回原始 JavaScript 对象，`tools/index.js` 统一通过 `return-adapter.js` 包装后注册。**

```javascript
// tools/task-tools.js
async function task_create(params) {
  const task = await taskObject.create(params);
  return { task, success: true };  // ← 原始对象
}

// tools/index.js
import { adaptReturn, adaptError } from './return-adapter.js';

api.registerTool({
  name: 'task.create',
  execute: async (_id, params) => {
    try {
      const result = await task_create(params);
      return adaptReturn(result);  // ← 统一包装
    } catch (err) {
      return adaptError(err);
    }
  }
});
```

---

## 边界约定

| 层级 | 职责 | 不做什么 |
|------|------|----------|
| Tool Handler | 业务逻辑、参数校验、调用对象方法 | 不处理返回格式、不捕获全部异常（抛出让外层处理） |
| `return-adapter.js` | `JSON.stringify` + `{ content: [...] }` 包装 | 不处理业务逻辑 |
| `tools/index.js` | 注册工具、try-catch 包装、调用 adaptReturn/adaptError | 不处理业务逻辑 |

---

## 错误格式

```json
{
  "content": [{ "type": "text", "text": "{\"error\":\"task 不存在: task-001\"}" }],
  "isError": true
}
```

Agent 可通过解析 `content[0].text` 判断操作是否成功。
