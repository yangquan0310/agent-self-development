# ADR-001：基础目录从硬编码改为可配置

> **状态**：建议中  
> **日期**：2026-05-13  
> **决策优先级**：🔴 P0  
> **可逆性**：可逆

---

## 背景

当前代码中多处硬编码了 Linux root 用户的绝对路径 `/root/.agent`：

- `src/index.js:58` — `const baseDir = '/root/.agent'`
- `src/common/adapters/state.js:15` — `DEFAULT_DIR = '/root/.agentsstate/...'`
- `src/common/adapters/memory.js:8` — `DEFAULT_DB = '/root/.agentsmemory/...'`
- `src/common/adapters/flow.js:21` — 默认 dbPath `/root/.agentsflows/...'`

这导致插件无法在 Windows、macOS 或非 root Linux 环境中运行，与 `package.json` 中声明的 `node >=18.0.0` 平台兼容性承诺冲突。

---

## 决策

将所有硬编码的 `/root/.agent` 替换为**可配置的基础目录**，按以下优先级解析：

1. 环境变量 `OPENCLAW_AGENT_DIR`
2. `api.config?.agentDir`（OpenClaw 核心暴露的配置）
3. `os.homedir() + '/.agent'`（跨平台默认值）

---

## 方案

### 新增 `src/common/paths.js`

```javascript
import { homedir } from 'os';
import { join } from 'path';

export function resolveBaseDir(api) {
  return process.env.OPENCLAW_AGENT_DIR 
    || api?.config?.agentDir 
    || join(homedir(), '.agent');
}

export function resolveStateDir(baseDir) {
  return join(baseDir, 'state', 'agent-self-development');
}

export function resolveMemoryDb(baseDir, agentId) {
  return join(baseDir, 'memory', `${agentId}.sqlite`);
}

export function resolveFlowsDb(baseDir) {
  return join(baseDir, 'flows', 'registry.sqlite');
}
```

### 修改入口（src/index.js）

```javascript
import { resolveBaseDir } from './common/paths.js';

const baseDir = resolveBaseDir(api);
```

### 修改适配器

各 adapter 的 `DEFAULT_*` 常量改为接受 `baseDir` 作为构造参数，不再包含硬编码路径。

---

## 影响

| 影响面 | 说明 |
|--------|------|
| 兼容性 | Windows/macOS/其他 Linux 用户可正常运行 |
| 现有用户 | 不变（Linux root 用户的 `homedir()` 仍是 `/root`，向后兼容） |
| 测试 | 可通过 `OPENCLAW_AGENT_DIR` 指向临时目录进行隔离测试 |
| 文档 | 需在 README 中说明环境变量配置方式 |

---

## 替代方案

| 方案 | 说明 | 拒绝原因 |
|------|------|----------|
| A. 保持现状 | 仅支持 Linux root | 与 Node.js 跨平台承诺冲突 |
| B. 仅使用 `process.env.HOME` | 不处理 Windows | `os.homedir()` 已覆盖 |
| C. 从 `api` 强制获取 | 要求 OpenClaw 核心暴露配置 | 保留环境变量作为降级方案 |
