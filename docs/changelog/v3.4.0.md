- Assessment skill — Agent evaluates task complexity before creating Plan
- `[NEED_PLAN]` marker — Agent signals intent to create a Plan

- **Removed plugin-side `_shouldUseMetacognition()`**: plugin no longer judges task complexity
- Simple tasks (queries, translations) incur zero overhead — no task file created
