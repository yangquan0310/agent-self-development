# v3.3.0 — 2026-04-29

## Added
- 6-dimension personality model (added "procedural memory" / If-Then rules)
- `revising` status — Plan can be revised and re-submitted for approval

## Changed
- **Unified task JSON**: all scattered keys merged into single `task:{runId}`
  - Removed: `plan:{runId}`, `event:{runId}`, `deviation:{runId}:{phaseId}`, `attribution:{runId}:{deviationId}`, `session_list:{runId}`, `wm:{runId}:tools`
- Personality update triggered immediately after Event archival (instead of daily cron)

## Removed
- Cron system (`src/common/adapters/cron-adapter.js`)
- Diary system (`src/personality/diary-manager.js`, `memory-adapter` diary methods)
