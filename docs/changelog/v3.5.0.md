# v3.5.0 — 2026-05-04

## Added
- `Heartbeat` module — background status monitoring via `heartbeat_prompt_contribution`
- Native `subagent_spawning` / `subagent_spawned` / `subagent_ended` hooks
- `before_agent_finalize` hook for unified quality checking and status marker parsing
- `Stream` module — streaming output buffering and aggregation
- `gateway_stop` resource cleanup interface

## Changed
- **Hooks compliance refactor**: `llm_output` and `agent_end` are now pure observation hooks
  - `monitoring` skill injection moved from `llm_output` to `before_prompt_build`
  - `development` skill injection moved from `agent_end` to `before_prompt_build`
  - `working_memory` skill changed to `reference_only` (no longer auto-injected)
- `[NEED_PLAN]` detection migrated from `llm_output` to `before_agent_finalize`
- `task.event` nested structure removed; `deviations`, `attributions`, `outcome` promoted to top-level fields
- `planning` skill version updated to 3.5.0

## Fixed
- `crypto.randomUUID()` crash — missing `crypto` import in ESM
- Hard-coded `MAX_ARCHIVED_TASKS` (50) now respects config
- `sessionId` semantic duplication (`session:${taskFamily}:${taskFamily}`)
- Memory connection leak — added `close()` method for SQLite cleanup

## Removed
- `src/common/event.js` (redundant, no module referenced it)
- Unused `dirname` import from `src/index.js`
- Unused `task`/`flow`/`memory`/`hook` instances from `src/index.js`
