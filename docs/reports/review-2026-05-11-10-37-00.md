## 3. 代码质量审查 — 逐文件意见

### 3.1 `openclaw.plugin.json` — **[BLOCKER]**

**位置**：第 15-21 行
**问题**：JSON 语法错误。`injectionMode` 配置对象结束后缺少逗号（`,`），导致后续 `metacognition` 配置块被解析为 `injectionMode` 对象内部的一部分。

```json
      "injectionMode": {
        ...
        "description": "..."
      }          // ← 这里缺少 ,
        "type": "object",   // ← 被错误地解析为 injectionMode 的属性
```

**严重度**：🔴 **BLOCKER** — 插件配置文件无法被 JSON.parse 正确解析，导致配置加载失败。

**修复建议**：在 `injectionMode` 对象闭合括号后添加逗号：
```json
      "injectionMode": {
        ...
      },
      "metacognition": {
```

---

### 3.2 `src/tools/metacognition-tools.js` — **[WARNING]**

**位置**：第 271 行，`update_task_status` 函数返回值
**问题**：`previousStatus` 逻辑错误。代码先执行 `task.status = status` 赋值，然后返回 `previousStatus: task.status`，导致 `previousStatus` 永远等于新状态而非旧状态。

```javascript
    task.status = status;           // ← 旧状态被覆盖
    ...
    return { success: true, runId, status, previousStatus: task.status };
                                    // ← previousStatus 现在是新状态
```

**严重度**：🟡 **WARNING** — API 语义错误，但核心功能（状态更新）不受影响。

**修复建议**：在赋值前保存旧状态：
```javascript
    const previousStatus = task.status;
    task.status = status;
    ...
    return { success: true, runId, status, previousStatus };
```

---

### 3.3 `src/index.js` — **[WARNING]**

**位置**：第 58 行
**问题**：硬编码基础目录路径 `const baseDir = '/root/.agent';`。在不同用户环境、不同 OS 或非 root 用户下会失效。

**严重度**：🟡 **WARNING** — 环境可移植性问题。

**修复建议**：使用 `os.homedir()` 或从环境变量/配置中读取基础目录。
