## 风险与备注

1. **事件文件路径推断**：当前通过 `task.createdAt` 推断事件文件路径（`.agent/events/{date}/{HH-MM-SS}.md`）。如 Agent 创建事件文件的时间与 task.createdAt 不一致，可能无法找到对应事件文件。建议后续在 task 中显式存储 `eventFilePath` 字段。

2. **文件变更审计的完整性**：`_auditFileChange` 依赖事件文件存在且包含「变更记录」章节。如 Agent 未按规范创建/更新事件文件，审计追踪将不完整。

3. **向后兼容**：Personality 和 Metacognition 均保留了对 `task.deviations` / `task.attributions` 的回退逻辑，确保旧任务正常工作。

4. **占位符功能**：系统层 State/Flow/心跳统计已标注为 [占位符]，当前无消费者，不影响核心功能。
