## 4. 合规审查

### 4.1 after_tool_call 合规性

**AGENTS.md 2.1 规则**：`after_tool_call` 是**纯观察型钩子**，只能看、不能注入，不能返回 action。

**实际实现**：
```javascript
// src/index.js
api.on('after_tool_call', async (event) => {
  // 只观察和记录日志
  logInfo(logger, `[agent-autobiography] after_tool_call: ${toolName}`);
  
  // 通过 enqueueNextTurnInjection 注入（这是 OpenClaw 框架的合法 API）
  const { shouldInject, idempotencyKey, prependContext } = evaluateAfterToolCall(event);
  if (shouldInject) {
    await enqueueInjection(api, logger, idempotencyKey, prependContext);
  }
}, { priority: 50 });
```

**审查结果**：✅ 合规
- `after_tool_call` 只做观察和日志记录
- 注入通过 `enqueueNextTurnInjection` API 完成（OpenClaw 框架级注入，非 hook 返回值）
- 未直接返回 `{ action }` 对象

---

### 4.2 before_prompt_build 合规性

**AGENTS.md 2.1 规则**：`before_prompt_build` 是**决策/注入型钩子**，只能使用 `prependSystemContext` 注入。

**实际实现**：
```javascript
// src/index.js
api.on('before_prompt_build', async (event) => {
  const { shouldInject, idempotencyKey, prependContext } = await evaluateBeforePromptBuild(context);
  if (shouldInject) {
    await enqueueInjection(api, logger, idempotencyKey, prependContext);
  }
}, { priority: 50 });
```

**审查结果**：✅ 合规
- 使用 `enqueueNextTurnInjection` 注入 prepend context
- 符合 OpenClaw `before_prompt_build` 钩子规范
