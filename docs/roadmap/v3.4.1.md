# v3.4.1 更新计划：日志审计、流式输出适配、指令强化

## 设计目标

- 将任务全生命周期关键事件写入结构化日志（JSONL），支持事后审计与故障定位
- 适配 OpenClaw 流式 `llm_output`：缓冲聚合 chunk，避免标记检测失败与重复注入
- 强化 skill 注入指令的约束力，降低 Agent 忽视/脱敏概率
- 修复已知隐患：skill 加载失败静默跳过、版本号不一致、重复注入疲劳

### 2. 流式 `llm_output` 适配
- [x] **新增 `src/common/stream.js`：流式输出处理（Stream）**
  - `append()` / `peek()` / `flush()` / `clear()` / `clearAll()` / `getActiveRunIds()`
- [x] **新增 `src/common/event.js`：Event 事件对象（面向对象封装）**
  - `isStreamChunk()` / `isStreamEnd()` / `getText()` / `classify()`
  - 覆盖 `stream === true` / `chunk` / `delta` / `done` / `finished` / `output` / `text` 多种格式
- [x] **改造 `Metacognition.onLlmOutput`**
  - 新增 `_resolveOutput(event, runId)` 方法，按事件类型分流处理
  - 流式 chunk → 只缓冲，return null（不检测、不注入）
  - 流结束 / 非流式 → 获取完整输出，继续原有 `[NEED_PLAN]` + monitoring 逻辑
  - `agent_end` 时清理残留缓冲区
- [x] **非流式安全兜底**
  - `agent_end` 强制 `streamBuffer.clear(runId)`，防止流未正常结束导致残留
- [x] **调试支持**
  - `_resolveOutput` 中记录 `classify` 结果和 event keys，便于确认 Gateway 实际事件格式
