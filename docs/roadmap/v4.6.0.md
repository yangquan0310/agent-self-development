## 核心工作流：四阶段自适应循环（ADAPT Loop）

```
┌─────────────────────────────────────────────┐
│                                             │
│   任务创建 → 偏差分析 → 归因 → 自我调节      │
│      ↑                          │            │
│      └────────── (反馈) ────────┘            │
│                                             │
└─────────────────────────────────────────────┘
```

### Phase 1：任务创建（Task Creation）

**触发条件**：任何任务执行时

**输入**：任务目标、约束条件、成功标准

**输出**：创建 `event.md`

### Phase 2：偏差分析（Deviation Analysis）

**触发条件**：任务执行过程中 / 完成后

**分析维度**：范围、时间、质量、资源、沟通、技术

**输出**：偏差类型 + 严重程度（P0/P1/P2）

### Phase 3：归因（Attribution）

**触发条件**：偏差分析完成后

**分析内容**：内部可控 / 内部不可控 / 外部可控 / 外部不可控

**输出**：根因 + 改进策略

### Phase 4：自我调节（Self-Regulation）

**触发条件**：归因完成后

**调节动作**：

| 动作 | 条件 | 结果 |
|------|------|------|
| 同化 | 技能存在但不适用 | 修改/细化现有技能 |
| 顺应 | 技能不存在 | 创建新技能 |
| 跳过 | 无需技能变更 | 仅记录经验教训 |
