# v3.6.0 Roadmap: Project Management Document System

> **目标**：建立标准化的项目文档体系，让多 Agent 能在同一项目中协作
> **状态**：已完成
> **完成时间**：2026-05-08

---

## 设计目标

1. **项目文档标准化**：定义四文件契约（README / metadata.json / SKILL.md / TODO.md），作为所有 Agent 共享的项目上下文
2. **目录结构规范化**：用英文命名替代中文，符合开源项目惯例
3. **角色分工明确化**：建立产品经理 / 程序员 / 审核三个角色，各司其职
4. **文档责任可追溯**：每个文档都有明确的创建者、维护者、审查者

## 项目文档体系（四文件契约）

```
项目根目录/
├── README.md          # 项目总览 —— 人类可读
├── metadata.json      # 机器可读架构
├── src/               # 技术实现
│   └── CONVENTIONS.md  # 技术规范
├── docs/              # 项目文档
│   ├── roadmap/        # 版本路线图
│   └── COLLABORATION.md # 协作协议
├── agents/            # 角色定义
│   ├── product-manager.md
│   ├── developer.md
│   └── reviewer.md
└── skills/            # 技能
    ├── project-context/
    └── skill-creator/
```

## 命名规范

| 类别 | 规范 | 示例 |
|------|------|------|
| 目录名 | 英文小写，kebab-case | `project-context/`, `skill-creator/` |
| 文件名 | 英文大写（Markdown）或 camelCase（JS） | `CONVENTIONS.md`, `TODO_TEMPLATE.md` |
| 角色文件 | 英文小写，kebab-case | `product-manager.md`, `developer.md` |
| 版本文件 | `v{x.y.z}.md` | `v3.6.0.md`, `v4.0.0.md` |
| 标记 | 英文大写，方括号 | `[DOC_UPDATE]`, `[APPROVED]` |
