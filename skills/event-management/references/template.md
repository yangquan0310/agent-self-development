# Event.md Template Reference

Structure of `.agent/events/{YYYY-MM-DD}/{runId}.md` generated by `event.report`.

## Rendering Source

All data comes from `task.json` at generation time. No incremental updates.

## Sections

### 1. Metadata

```markdown
# Event: {runId}

- **Status**: {status}
- **Type**: {taskType}
- **Created**: {createdAt}
- **Completed**: {updatedAt (if status === completed)}
```

### 2. Plan

```markdown
## Plan

**Goal**: {plan.context.goal}

**Constraints**:
- {constraint1}
- {constraint2}

**Success Criteria**:
- {criterion1}
- {criterion2}

**Phases**:
| ID | Name | Goal | Status |
|----|------|------|--------|
| p1 | {name} | {goal} | completed |
| p2 | {name} | {goal} | pending |
```

### 3. Execution

```markdown
## Execution

**Completed Phases**: {count} / {total}
**Current Phase**: {currentPhase + 1}

Phase completion status derived from `plan.execution.phases[].status`.
```

### 4. Deviations

```markdown
## Deviations

### {deviation.type} — {deviation.timestamp}
{deviation.description}

**Impact**: {deviation.impact}
```

One entry per item in `task.deviations[]`.

### 5. Attributions

```markdown
## Attributions

### Attribution — {attribution.timestamp}
**Root Cause**: {attribution.rootCause}
**Strategy**: {attribution.strategy}

**Impact**: {attribution.impact}
```

One entry per item in `task.attributions[]`.

### 6. Outcome

```markdown
## Outcome

**Summary**: {outcome.summary}

**Artifacts**:
- {artifact1}
- {artifact2}

**Metrics**:
{outcome.metrics}
```

## Important Notes

- Template source: `src/assets/event.md`
- Rendering is **one-shot** at task completion
- No live link to task.json after generation
- To update event.md, modify task.json and re-run `event.report`
- event.report overwrites existing event.md if present
